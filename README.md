# ReFind – Intelligent Lost-and-Found Management System

ReFind is a Python-based lost-and-found web application designed for college campuses.

### Features
- Report lost and found items
- Upload item images
- Store reports using SQLite
- NLP-based item matching
- TF-IDF and cosine similarity
- Matching based on category, color, and location
- Streamlit web interface

### Technologies
- Python
- Streamlit
- SQLite
- Scikit-learn
- NLP

### How to Run

```bash
pip install -r requirements.txt
python -m streamlit run app.py
